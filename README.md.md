# Knowledge Base

A personal collection of notes, concepts, experiments, and references gathered while learning and building things.

This repository is my long-term knowledge store—a place to document what I learn, revisit concepts, connect ideas across disciplines, and keep useful information accessible.

The contents span computer science, mathematics, programming languages, machine learning, networking, software engineering, and project-specific notes. Some pages contain detailed explanations; others are quick references, code snippets, observations, or ideas worth exploring later.

## What's Inside

|Area|Contents|
|---|---|
|Mathematics|Linear algebra, probability, statistics, discrete mathematics, calculus, and problem-solving|
|Computer Science|Data structures, algorithms, operating systems, memory, compilers, and computer architecture|
|Networking|Network protocols, HTTP, TCP/IP, DNS, sockets, and network security|
|C++|Language features, memory management, STL, systems programming, and compiler development|
|Java|Core Java, JVM, concurrency, collections, Spring Boot, and application development|
|Machine Learning|Fundamentals, mathematical intuition, algorithms, experiments, and implementations|
|Software Engineering|Design patterns, clean code, testing, debugging, Git, CI/CD, and development workflows|
|Backend & Distributed Systems|APIs, microservices, Kafka, databases, messaging, and system design|
|Projects|Implementation notes, architecture, design decisions, problems encountered, and lessons learned|
|Miscellaneous|Useful commands, references, ideas, and anything that doesn't fit neatly elsewhere|

## How I Use This Repository

- **Capture:** Save concepts, commands, code snippets, and observations worth keeping.
    
- **Understand:** Write explanations in my own words instead of relying solely on copied material.
    
- **Connect:** Link related ideas across mathematics, computer science, and practical engineering.
    
- **Build:** Keep implementation notes and lessons from personal and professional projects.
    
- **Revisit:** Use these notes as a reference when solving problems or returning to a topic after a long gap.
    

This is a living repository. Notes may be incomplete, evolving, experimental, or in need of revision.

## Notes and Conventions

Notes can take different forms depending on the subject:

- **Concepts:** Explanations, mental models, diagrams, and examples.
    
- **Reference notes:** Syntax, commands, formulas, APIs, and quick reminders.
    
- **Implementation notes:** Code snippets, experiments, and debugging observations.
    
- **Learning notes:** Questions, incomplete understanding, and topics to investigate further.
    
- **Project notes:** Architecture, trade-offs, decisions, and practical lessons.
    

I don't aim to make every note comprehensive or perfectly formatted. The goal is to preserve useful knowledge and make it easier to retrieve and build upon later.

## Guiding Principle

> Learn it, understand it, write it down, apply it, and return to it when needed.

This repository represents an ongoing learning process, not a claim of mastery over every topic it contains.
